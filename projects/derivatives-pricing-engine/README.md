# Derivatives Pricing Engine

A compact quantitative-finance project focused on option pricing and numerical methods.

## Implemented methods

- Black-Scholes pricing for European calls and puts
- Put-call parity
- Greeks: Delta, Gamma, Vega, Theta and Rho
- Implied-volatility estimation by bisection
- Cox-Ross-Rubinstein binomial pricing
- Monte Carlo pricing for European options

## Why this project

The goal is to connect financial theory with clean numerical implementation and to compare several standard derivatives-pricing approaches.

## Tech

Python · NumPy · SciPy · Quantitative Finance · Numerical Methods

## Files

- `pricing.py` — Black-Scholes, Greeks and implied volatility
- `numerical.py` — binomial tree and Monte Carlo pricing
