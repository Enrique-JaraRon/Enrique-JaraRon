# Market Risk & VaR Analytics

A compact market-risk project comparing standard Value-at-Risk methodologies and backtesting logic.

## Implemented methods

- Historical VaR
- Gaussian parametric VaR
- Kernel Density VaR
- Expected Shortfall
- VaR violation ratio
- Simple out-of-sample backtesting

## Objective

The project illustrates how different distributional assumptions affect market-risk estimates and how VaR models can be evaluated using observed violations.

## Tech

Python · NumPy · Pandas · SciPy · Statistics · Risk Management

## Files

- `var_models.py` — VaR and Expected Shortfall estimators
- `backtest.py` — violation analysis and backtesting helpers
